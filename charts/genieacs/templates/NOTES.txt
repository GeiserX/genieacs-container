1. To access the GenieACS UI, follow these instructions:

{{- if or .Values.ingress.enabled .Values.httpRoute.enabled }}
   The GenieACS UI is accessible through the configured route resource(s):

   {{- if .Values.ingress.enabled }}
   Ingress:
   {{- range .Values.ingress.hosts }}
     http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}{{ with .paths }}{{ (index . 0).path }}{{ end }}
   {{- end }}
   {{- end }}

   {{- if .Values.httpRoute.enabled }}
   {{- $path := "/" }}
   {{- with .Values.httpRoute.matches }}
   {{- with (index . 0).path }}
   {{- $path = .value | default "/" }}
   {{- end }}
   {{- end }}
   HTTPRoute host/path:
   {{- range .Values.httpRoute.hostnames }}
     {{ . }}{{ $path }}
   {{- else }}
     (any hostname accepted by the Gateway listener){{ $path }}
   {{- end }}
   {{- end }}
{{- else }}
   NOTE: The ingress and HTTPRoute are disabled, and you might need to use port-forwarding to access the UI.

   Run the following command to forward the port:

     kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "genieacs.fullname" . }}-http 8080:{{ .Values.service_http.port_http }}

   Then access the UI at: http://127.0.0.1:8080/
{{- end }}
