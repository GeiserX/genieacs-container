# GenieACS Container

Docker image and Helm chart for [GenieACS](https://genieacs.com), an open-source TR-069 ACS: GenieACS
and MongoDB with Docker Compose on one host, or on Kubernetes with the chart.

- [Getting started](getting-started.md): Docker Compose, `docker run`, Helm with a bundled, external or
  Secret-sourced MongoDB, Helmfile, the chart's main values
- [Configuration](configuration.md): ports, volumes, environment variables, security
- [Usage](usage.md): the four services, the optional simulator and MCP services, extension scripts, logs
- [Troubleshooting](troubleshooting.md): logs, MongoDB connection, reporting a bug
- [Development](development.md): building the image and contributing
- [Related projects](related.md): the Ansible, MCP, Home Assistant, simulator and ISP tools
